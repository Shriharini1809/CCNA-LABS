# LAB 1 - Basic Router Configuration

## Objective
Configure a Cisco router with basic settings and establish communication between two LAN networks using directly connected routing.

---

## Devices Used

- 1 Cisco 1941 Router
- 2 Cisco 2960 Switches
- Each Switch connected with 12 device
- Copper Straight-Through Cables

---

## Topics Covered

- Basic Router Configuration
- Interface Configuration
- IP Address Assignment
- Default Gateway Configuration
- Directly Connected Routing
- Interface Verification
- End-to-End Connectivity

---

## Verification Commands

```bash
show ip interface brief
```

```bash
ping <destination-ip>
```

## Files Included

- basic-router-configuration.docx
- basic-router-configuration.pkt

## Result

Successfully configured a Cisco router and established communication between two LAN networks using directly connected routing.
