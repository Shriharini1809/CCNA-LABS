# LAB 2 - Static Routing Configuration (Two Routers)

## Objective

Configure static routing between two Cisco routers to enable communication between two different LAN networks.

---

## Devices Used

- 2 Cisco 1941 Routers
- 2 Cisco 2960 Switches
- Each Switch connected with 12 PC's
- Copper Straight-Through Cables

---

## Topics Covered

- Static Routing
- Next-Hop Address
- Point-to-Point Network (/30)
- Routing Table
- Router-to-Router Communication
- ARP Process
- End-to-End Connectivity

---

