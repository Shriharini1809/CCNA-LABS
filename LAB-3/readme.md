# LAB 3 - Three Router Static Routing

## Objective

Configure three Cisco routers using static routing and establish communication between two different LAN networks through an intermediate router.

---

## Devices Used

- 3 Cisco 1941 Routers
- 2 Cisco 2960 Switches
- Each Switch connected with 12 PC's
- Copper Straight-Through Cables

---

## Topics Covered

- Static Routing
- Multi-Hop Routing
- Router-to-Router Communication
- Point-to-Point Networks (/30)
- Next-Hop IP Address
- Routing Table Verification
- Packet Forwarding
- ARP Resolution
- End-to-End Connectivity
- Network Troubleshooting
