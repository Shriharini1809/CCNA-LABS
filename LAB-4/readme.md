# Day 4 - Dynamic Routing using RIP (Routing Information Protocol)

## 📌 Objective

Configure Dynamic Routing using RIP Version 2 and enable automatic route exchange between three Cisco routers.

---

## 🛠️ Tools Used

- Cisco Packet Tracer
- Cisco 1941 Routers
- Cisco 2960 Switches

---

## 🌐 Network Topology

PC1 → Switch → R1 → R2 → R3 → Switch → PC2

---

## 📚 Concepts Covered

- Dynamic Routing
- RIP Version 2
- Network Command
- Hop Count
- Administrative Distance
- Next Hop
- Routing Table
- RIP Updates
- Route Verification

---

## ⚙️ Verification Commands

```bash
show ip interface brief

show ip route

show ip protocols

ping
```

---

## ✅ Result

Successfully configured RIP Version 2 on three Cisco routers. The routers automatically exchanged routing information, updated their routing tables dynamically, and enabled successful communication between different LANs.
